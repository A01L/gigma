# Архитектура Gigma

## Стек

- **Electron 45** (Chromium + Node 24) — одна кодовая база для Windows и macOS, без нативных модулей.
- **React 19 + TypeScript** — только для «хрома» интерфейса (панели, инспектор). Холст на React не завязан.
- **SQLite через `node:sqlite`** (встроен в Node 24) — хранилище проектов.
- **MCP SDK** — встроенный сервер для ИИ.

## Процессы

```
┌──────────────────── main (Node) ─────────────────────┐
│ library.ts  — библиотека проектов (userData/library)  │
│ storage.ts  — файл .gigma (SQLite)                    │
│ mcp.ts      — MCP-сервер 127.0.0.1:7331 (HTTP)        │
│ index.ts    — окно, меню, протокол gigma-blob://      │
└───────────┬──────────────────────────────▲───────────┘
   IPC: doc:apply (пакеты изменений)       │ cmd:request / cmd:response
┌───────────▼──────── renderer ────────────┴───────────┐
│ editor/editor.ts   — документ, undo, индекс, автосейв │
│ editor/render.ts   — Canvas-рендерер                  │
│ editor/canvas.ts   — ввод: выбор, перемещение, ресайз │
│ editor/commands.ts — шина команд (MCP, плагины)       │
│ editor/svg*.ts, clipboard.ts, figma-clipboard.ts      │
│ ui/*               — панели, тулбар, инспектор        │
└───────────────────────────────────────────────────────┘
bin/gigma-mcp.cjs — stdio⇄HTTP мост для Claude Desktop
```

## Модель документа

Повторяет модель Figma, чтобы обмен с ней был без потерь: узлы `FRAME / GROUP / RECTANGLE / ELLIPSE /
TEXT / VECTOR`, координаты относительно родителя, массивы `fills` и `strokes`, картинки как `IMAGE`-заливка
по хэшу, порядок слоёв — дробные индексы (fractional indexing), как в Figma. Группы, как и в Figma,
автоматически подгоняются под детей.

## Хранилище и формат `.gigma`

Файл `.gigma` — это одна база SQLite:

| таблица | содержимое |
| --- | --- |
| `meta`  | метаданные документа, превью |
| `pages` | страницы (JSON) |
| `nodes` | один узел — одна строка (JSON), индекс по странице |
| `blobs` | картинки по SHA-1, без дублей |

- Сохранение инкрементальное: редактор копит изменённые узлы и раз в 250 мс отправляет пакет одной транзакцией.
- WAL-журнал: падение приложения не портит файл.
- Проекты живут в локальной библиотеке приложения. **Экспорт** проекта или выбранных страниц создаёт
  самодостаточный `.gigma` со всеми картинками. **Импорт** — либо как новый проект в библиотеку, либо
  страницами в открытый проект (id пересоздаются, можно импортировать повторно).
- Картинки отдаются в UI по протоколу `gigma-blob://` прямо из базы, не через base64 в памяти JS.

## Производительность

- Рендер только по необходимости (dirty-флаг + `requestAnimationFrame`).
- R-дерево (`rbush`) по мировым координатам: отсечение по видимой области и hit-test за O(log n),
  инкрементальное обновление только изменённых поддеревьев.
- LOD: субпиксельные объекты пропускаются, мелкий текст рисуется полосками.
- Кэш `Path2D` для векторов, кэш раскладки текста, картинки декодируются один раз в `ImageBitmap`.
- Виртуализированный список слоёв (рисуются только видимые строки).
- Рендерер изолирован в `drawScene()`: при необходимости меняется на WebGL/CanvasKit (Skia) без
  изменений в редакторе.

## Совместимость с Figma

- **Gigma → Figma**: копирование кладёт SVG; Figma превращает его в редактируемые слои.
- **Gigma → Gigma**: в SVG вшиты точные данные узлов (`<metadata><gigma-data>`), картинки помечены `data-hash`.
- **Figma → Gigma**: нативный буфер Figma (`fig-kiwi` в HTML) декодируется: схема kiwi вшита в сам буфер,
  сжатие deflate/zstd. Фреймы, группы, фигуры, текст, цвета, векторы (через `fillGeometry`) переносятся.
  Картинок в буфере Figma нет (они на серверах Figma) — вместо них ставится заглушка.

## MCP

Сервер stateless, Streamable HTTP, слушает только `127.0.0.1`, проверяет `Host`/`Origin` (защита от
DNS-rebinding). Каждый инструмент — это команда шины, выполняемая в редакторе как обычное действие
с undo. `export_png` возвращает картинку, чтобы ИИ видел результат своей работы.

## Плагины (план)

Плагины будут работать через ту же шину команд (`src/shared/commands.ts`), что и MCP: изолированный
iframe/worker с API `gigma.createFrame(...)` и т.п., права на уровне манифеста. Видео и режим разработчика
(code/dev mode) в планы не входят.
