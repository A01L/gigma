# Плагины Gigma: как сделать свой

Этот документ описывает всё, что нужно, чтобы написать плагин для Gigma: формат пакета, как плагин запускается, полный API и справочник команд. Его можно целиком отдать ИИ-ассистенту (Claude, ChatGPT и другим) вместе с описанием идеи, и он напишет плагин. Готовая подсказка для этого есть в конце, в разделе «Как попросить ИИ написать плагин».

## Коротко

- Плагин это обычная веб-страница: `index.html` с разметкой, стилями и скриптом. Никаких сборщиков, фреймворков и Node.js не нужно.
- Рядом лежит `manifest.json` с названием и настройками.
- Эти файлы упаковываются в zip-архив с расширением `.plug.gigma`.
- В странице плагина уже есть объект `gigma`. Через него плагин читает выделение, создаёт и меняет слои, показывает уведомления.
- Плагин работает в песочнице: у него нет доступа к файлам, к другим проектам и к интернету (интернет только через `gigma.fetch` и `gigma.capturePage` и только с разрешением `network`).

## Быстрый старт

1. В Gigma откройте Настройки, раздел «Плагины», и нажмите «Скачать шаблон плагина». В архиве лежит папка `my-plugin` с рабочим примером и этот документ.
2. Распакуйте архив. Нажмите «Установить из папки…» и выберите папку `my-plugin`. Плагин появится в списке с пометкой «Папка».
3. Откройте любой проект, нажмите правой кнопкой по холсту, выберите «Плагины» и свой плагин. Или нажмите Ctrl+K и начните вводить его название.
4. Меняйте `index.html` в любом редакторе. Чтобы увидеть изменения, закройте окно плагина и запустите его снова: файлы читаются с диска при каждом запуске, переустанавливать не нужно.
5. Когда плагин готов, упакуйте содержимое папки в zip и переименуйте файл в `my-plugin.plug.gigma`. Этот файл можно отдать кому угодно: он ставится кнопкой «Установить плагин…» или двойным щелчком.

## Формат пакета

`.plug.gigma` это zip-архив. Файлы могут лежать в корне архива или в одной папке внутри него.

```
my-plugin.plug.gigma
├── manifest.json      обязательный
├── index.html         страница плагина (имя задаётся полем "main")
├── icon.svg           необязательно: значок в меню и в настройках
└── ...                любые свои файлы: скрипты, стили, картинки, шрифты
```

Ограничения: до 2000 файлов и до 64 МБ в распакованном виде.

### manifest.json

```json
{
  "id": "my-plugin",
  "name": "My plugin",
  "version": "1.0.0",
  "description": "Что делает плагин, одной строкой",
  "author": "Ваше имя",
  "main": "index.html",
  "icon": "icon.svg",
  "ui": { "width": 300, "height": 360 },
  "permissions": []
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор: от 2 до 49 символов, только строчные латинские буквы, цифры и дефис. Плагин с тем же `id` при установке заменяет старый. |
| `name` | да | Название в меню и в заголовке окна. |
| `version` | да | Версия, например `"1.0.0"`. |
| `description` | нет | Короткое описание для списка плагинов. |
| `author` | нет | Автор. |
| `main` | нет | HTML-файл плагина. По умолчанию `index.html`. |
| `icon` | нет | Картинка внутри пакета (svg или png), лучше квадратная. |
| `ui` | нет | Размер окна плагина в пикселях: `{ "width": 300, "height": 400 }`. Ширина от 160 до 900, высота от 80 до 800. Значение `false` запускает плагин без окна: он должен сделать работу и вызвать `gigma.close()`. |
| `permissions` | нет | Список разрешений. Сейчас одно: `"network"`, оно включает `gigma.fetch` и `gigma.capturePage`. В списке плагинов у такого плагина стоит пометка «Доступ в интернет». |

## Как работает плагин

Одновременно запущен один плагин. При запуске Gigma открывает небольшое окно поверх холста и загружает в него страницу из поля `main`. Окно можно перетаскивать за заголовок, крестик закрывает плагин.

Страница работает в изолированном фрейме:

- В ней есть обычный браузерный JavaScript, DOM, Canvas, таймеры. Нет Node.js, нет доступа к диску и к окну приложения.
- Страница грузит только файлы из своего пакета по относительным путям: `<script src="app.js">`, `<img src="img/logo.png">`. Встроенные `<script>` и `<style>` разрешены.
- Запросы в интернет прямо со страницы запрещены: `fetch('https://…')`, внешние скрипты, шрифты и картинки с сайтов не загрузятся. Для сети есть `gigma.fetch`.
- `localStorage` и cookies недоступны. Чтобы запомнить настройки, используйте `gigma.storage`.

Объект `gigma` появляется на странице до ваших скриптов. Подключать ничего не нужно.

### Готовые стили

Чтобы плагин выглядел как часть Gigma в светлой и тёмной теме, подключите готовую таблицу стилей:

```html
<link rel="stylesheet" href="/@gigma/ui.css" />
```

Она оформляет `body`, заголовки, `button`, `input`, `select`, `textarea`, ползунки и даёт несколько классов:

| Класс | Что делает |
|---|---|
| `button.primary` | Синяя основная кнопка. |
| `.row` | Строка: элементы в ряд с отступами, растягиваются поровну. Элемент с классом `.fixed` не растягивается. |
| `.grid` | Две колонки. |
| `.field` | Блок «подпись и поле» с нижним отступом. |
| `.card` | Плашка с фоном. |
| `.seg` | Переключатель из кнопок; активной кнопке дайте класс `on`. |
| `.muted` | Приглушённый текст. |
| `.full` | Ширина 100%. |

Цвета доступны как переменные CSS: `--bg`, `--panel`, `--panel-2`, `--border`, `--text`, `--text-2`, `--text-3`, `--accent`, `--danger`, `--radius`. Текущая тема записана в `document.documentElement.dataset.theme` (`"dark"` или `"light"`).

## API: объект `gigma`

Все методы возвращают `Promise`. Ошибки приходят как отклонённый `Promise` с понятным текстом, оборачивайте вызовы в `try / catch`.

### gigma.ready и gigma.info

`gigma.ready` это `Promise`, который выполняется, когда плагин связался с редактором. Результат (он же потом лежит в `gigma.info`):

```js
{
  plugin: { id, name, version, permissions },
  theme: 'dark' | 'light',
  locale: 'ru' | 'en',
  selection: [ /* выделенные слои, см. ниже */ ],
  page: { id, name }
}
```

```js
const info = await gigma.ready
console.log(info.selection.length)
```

### gigma.command(name, args)

Главный метод: выполняет команду над открытым документом и возвращает её результат. Команды те же, что у встроенного MCP-сервера Gigma: те же имена, те же аргументы, те же значения по умолчанию. Полный список в разделе «Справочник команд».

```js
const frame = await gigma.command('create_frame', { name: 'Card', x: 0, y: 0, width: 320, height: 200, fill: '#FFFFFF', cornerRadius: 16 })
await gigma.command('create_text', { text: 'Привет', x: 24, y: 24, fontSize: 20, parentId: frame.id })
await gigma.command('update_node', { id: frame.id, opacity: 0.9 })
```

Что важно знать:

- Координаты в пикселях. `x` и `y` слоя отсчитываются от левого верхнего угла его родителя (фрейма или группы). У слоёв на странице родителя нет, и координаты отсчитываются от начала страницы.
- Цвета задаются строкой: `"#FF5733"` или с прозрачностью `"#FF573380"`.
- Команды создания возвращают `{ id, type, name, x, y, width, height, parentId }`. Сохраняйте `id`, он нужен для следующих команд.
- Каждая команда это отдельный шаг отмены. Чтобы всё действие плагина отменялось одним Ctrl+Z, используйте `gigma.undoGroup`.

### gigma.selection()

Возвращает массив выделенных слоёв. Каждый слой это объект со всеми свойствами, плюс `absX` и `absY` (положение на странице).

Основные поля слоя:

| Поле | Описание |
|---|---|
| `id`, `name`, `type` | Тип один из: `FRAME`, `GROUP`, `RECTANGLE`, `ELLIPSE`, `TEXT`, `VECTOR`, `IMAGE`, `SECTION`, `SLICE`, `SPEC`, `CODE`, `ANNOTATION`. |
| `parentId` | `null` для слоёв на странице. |
| `x`, `y`, `width`, `height` | Положение относительно родителя и размер. |
| `absX`, `absY` | Положение на странице. |
| `rotation`, `opacity`, `visible`, `locked` | Поворот в градусах, прозрачность от 0 до 1. |
| `fills` | Массив заливок: `{ type: 'SOLID', color: { r, g, b, a } }`, градиенты `GRADIENT_LINEAR` / `GRADIENT_RADIAL` с полем `stops`, картинки `{ type: 'IMAGE', imageHash, scaleMode }`. Компоненты цвета от 0 до 1. |
| `strokes` | Массив обводок: `{ color, weight, align }`. |
| `effects` | Массив эффектов: `DROP_SHADOW`, `INNER_SHADOW` (`color`, `offset: { x, y }`, `radius`, `spread`), `LAYER_BLUR`, `BACKGROUND_BLUR` (`radius`). |
| `cornerRadius`, `cornerRadii` | Скругление: общее или по углам. |
| `characters`, `textStyle` | Текст и его оформление (для `TEXT`). |
| `layoutMode` и другие | Свойства авто-лейаута (для `FRAME`). |

Обратите внимание: в объектах слоёв цвет хранится как `{ r, g, b, a }` с числами от 0 до 1, а в аргументах команд цвет передаётся строкой `"#RRGGBB"`.

### События: gigma.on(name, handler)

```js
const off = gigma.on('selectionchange', (nodes) => { /* тот же формат, что у gigma.selection() */ })
off() // отписаться
```

| Событие | Данные | Когда |
|---|---|---|
| `selectionchange` | массив слоёв | Пользователь выделил другие слои. |
| `pagechange` | `{ id, name }` | Сменилась страница или список страниц. |
| `themechange` | `'dark'` или `'light'` | Пользователь сменил тему. Атрибут `data-theme` обновляется сам. |

### gigma.viewport()

Видимая часть холста: `{ x, y, width, height, centerX, centerY, zoom }` в координатах страницы. Удобно, чтобы ставить новые слои в центр экрана.

### gigma.undoGroup(fn)

Всё, что сделано внутри `fn`, становится одним шагом отмены.

```js
await gigma.undoGroup(async () => {
  for (const n of nodes) await gigma.command('update_node', { id: n.id, opacity: 0.5 })
})
```

Тонкость: авто-лейаут и экземпляры компонентов пересчитываются, когда группа закрывается. Если нужно прочитать размеры после авто-лейаута, читайте их после `undoGroup`.

`gigma.undo()` и `gigma.redo()` отменяют и повторяют шаг. Ctrl+Z и Ctrl+Shift+Z работают и тогда, когда курсор в окне плагина (кроме полей ввода).

### gigma.notify(text)

Показывает короткое сообщение внизу холста.

### gigma.close()

Закрывает плагин.

### gigma.resize(width, height)

Меняет размер окна плагина.

### gigma.storage

Постоянное хранилище плагина на этом компьютере, до 5 МБ. Значение это любые данные, которые превращаются в JSON.

```js
await gigma.storage.set('settings', { color: '#ff00aa', size: 20 })
const settings = (await gigma.storage.get('settings')) ?? { color: '#0d99ff', size: 10 }
```

### gigma.createImage(source)

Кладёт картинку в проект и возвращает её `imageHash`. `source` это data-URL (`data:image/png;base64,…`), `Blob`, `ArrayBuffer` или `Uint8Array`. Картинку можно нарисовать на `<canvas>`:

```js
const blob = await new Promise((r) => canvas.toBlob(r, 'image/png'))
const imageHash = await gigma.createImage(blob)
await gigma.command('create_image', { imageHash, x: 0, y: 0, width: 400, height: 300 })
// или залить существующий слой
await gigma.command('update_node', { id, fills: [{ type: 'IMAGE', imageHash, scaleMode: 'FILL' }] })
```

### gigma.fetch(url, { as })

Нужно разрешение `network`. Загружает адрес `http` или `https` и возвращает содержимое. `as` может быть `'text'` (по умолчанию), `'json'` или `'dataURL'`. Размер ответа до 32 МБ, ожидание до 30 секунд.

```js
const data = await gigma.fetch('https://api.example.com/items', { as: 'json' })
const picture = await gigma.fetch('https://example.com/photo.jpg', { as: 'dataURL' })
const imageHash = await gigma.createImage(picture)
```

### gigma.capturePage({ url, width, mobile, maxHeight })

Нужно разрешение `network`. Открывает сайт в скрытом изолированном окне и делает снимок страницы целиком. Возвращает `{ imageHash, width, height, title }`: картинка уже лежит в проекте, размеры даны в пикселях страницы.

| Аргумент | Описание |
|---|---|
| `url` | Адрес сайта. Без `https://` тоже можно. |
| `width` | Ширина окна: от 240 до 2560. Для компьютера обычно 1440, для телефона 390. |
| `mobile` | `true` открывает сайт как телефон (мобильный браузер, касания, двойная плотность). |
| `maxHeight` | Наибольшая высота снимка, по умолчанию 12000, не больше 16000. |

```js
const shot = await gigma.capturePage({ url: 'example.com', width: 1440 })
await gigma.command('create_frame', { name: shot.title, x: 0, y: 0, width: shot.width, height: shot.height })
```

## Частые задачи

### Поставить новый слой в центр экрана

```js
const v = await gigma.viewport()
await gigma.command('create_rectangle', { x: Math.round(v.centerX - 100), y: Math.round(v.centerY - 50), width: 200, height: 100, fill: '#0D99FF' })
```

### Изменить все выделенные слои

```js
const nodes = await gigma.selection()
if (!nodes.length) return gigma.notify('Сначала выделите слои')
await gigma.undoGroup(async () => {
  for (const n of nodes) await gigma.command('update_node', { id: n.id, cornerRadius: 12 })
})
```

### Тень и свечение

`effects` в `update_node` заменяет все эффекты слоя. Чтобы добавить к существующим, сначала прочитайте их из слоя. Цвет в команде задаётся строкой с прозрачностью, а из слоя приходит объектом, его нужно перевести:

```js
const hex = (c) => '#' + [c.r, c.g, c.b, c.a].map((v) => Math.round(v * 255).toString(16).padStart(2, '0')).join('')
const old = (node.effects ?? []).map((e) => ({ type: e.type, color: e.color ? hex(e.color) : undefined, x: e.offset?.x, y: e.offset?.y, radius: e.radius, spread: e.spread }))
await gigma.command('update_node', { id: node.id, effects: [...old, { type: 'DROP_SHADOW', color: '#00E5FF99', x: 0, y: 0, radius: 24 }] })
```

### Собрать блок авто-лейаутом

```js
const row = await gigma.command('create_frame', {
  name: 'Button', x: 0, y: 0, width: 10, height: 10, fill: '#2563EB', cornerRadius: 10,
  layoutMode: 'HORIZONTAL', padding: [10, 18, 10, 18], itemSpacing: 8,
  primaryAxisSizingMode: 'AUTO', counterAxisSizingMode: 'AUTO'
})
await gigma.command('create_text', { text: 'Купить', x: 0, y: 0, fontSize: 15, color: '#FFFFFF', parentId: row.id })
```

### Сложная вёрстка одним блоком

Команда `create_code` принимает HTML и CSS и рисует их как слой. Это удобно для таблиц, графиков и другой сложной вёрстки, которую долго собирать по координатам.

### Плагин без окна

В `manifest.json` укажите `"ui": false`. Страница всё равно загружается, но окна нет. Сделайте работу и закройтесь:

```html
<script>
  gigma.ready.then(async (info) => {
    for (const n of info.selection) await gigma.command('update_node', { id: n.id, opacity: 0.5 })
    gigma.notify('Готово')
    gigma.close()
  })
</script>
```

## Упаковка и распространение

1. Выделите файлы плагина (`manifest.json`, `index.html` и остальные) и сожмите их в zip. Можно сжать и саму папку, Gigma поймёт оба варианта.
2. Переименуйте архив: `название.plug.gigma`.
3. Установка: Настройки, «Плагины», «Установить плагин…». В установленной Gigma файл также открывается двойным щелчком.

В Windows через PowerShell:

```
Compress-Archive -Path my-plugin\* -DestinationPath my-plugin.zip
Rename-Item my-plugin.zip my-plugin.plug.gigma
```

В macOS и Linux:

```
cd my-plugin && zip -r ../my-plugin.plug.gigma . && cd ..
```

Установленные плагины лежат в папке, которую открывает кнопка «Открыть папку» в разделе «Плагины».

## Если что-то не работает

- Плагин не появился в списке. Проверьте `manifest.json`: это должен быть правильный JSON с полями `id`, `name`, `version`, а `id` должен состоять только из строчных латинских букв, цифр и дефисов.
- Окно пустое. Скорее всего, ошибка в скрипте. Покажите её прямо в окне: оберните код в `try / catch` и выведите `error.message` на страницу.
- «Unknown command». Имя команды написано с ошибкой, сверьтесь со справочником ниже.
- Сообщение вида «create_frame: width: Invalid input». Аргумент пропущен или не того типа.
- «this plugin has no "network" permission». Добавьте `"permissions": ["network"]` в манифест и запустите плагин заново.
- Картинка или шрифт с сайта не загружается. Прямые запросы в интернет запрещены. Загрузите файл через `gigma.fetch(url, { as: 'dataURL' })` или положите его в пакет.

## Как попросить ИИ написать плагин

Отправьте ассистенту этот документ целиком и добавьте просьбу по образцу:

```
Напиши плагин для Gigma по приложенной документации.

Что должен делать плагин: <опишите своими словами: что вводит пользователь,
какие кнопки и ползунки нужны, что должно появиться или измениться на холсте>.

Требования:
- Дай два файла целиком: manifest.json и index.html. Весь код в index.html,
  без сборщиков, без внешних библиотек и без запросов в интернет со страницы.
- Подключи /@gigma/ui.css и используй его классы.
- Работай с документом только через gigma.command и другие методы gigma
  из документации. Не выдумывай команды и аргументы: бери их из справочника.
- Изменения оборачивай в gigma.undoGroup. Ошибки показывай через gigma.notify.
- В конце напиши, как установить плагин из папки и как упаковать его в .plug.gigma.
```

Полученные файлы положите в одну папку и установите её кнопкой «Установить из папки…». Если что-то работает не так, опишите ассистенту, что происходит, и приложите текст ошибки.
