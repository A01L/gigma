HTML fileClaude

A plugin is a web page with a manifest, zipped into a .gplug file. It runs in a sandbox and talks to Gigma through the very commands the AI uses.

+ LinkBIUS@

Plugins in Gigma can fit a screen into every phone, pull data into tables, generate icons or turn a web page into layers.

gigma
Plugins
The tools you need, written by you

With a few one HTML file, a plugin can read the selection, create layers, use fetch with permission and keep its own settings, same tools the very commandsCodex an assistant calls over MCP.

⧉ 
<!-- index.html of a plugin -->
<button id="go">Round the selection</button>
<script>
  go.onclick = async () => {
    const nodes = await gigma.selection()
    await gigma.undoGroup(async () => {
      for (const n of nodes)
        await gigma.command('update_node', {
          id: n.id, cornerRadius: 16,
        })
    })
  }
</script>

Write it by hand or give the plugin docs to an AI along with your idea. Drop the .gplug file into Settings, Plugins, and it is ready to run from Ctrl+K.
