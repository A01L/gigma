Plugins
The tools you need, written by you

With one HTML file, a plugin can read the selection, create layers, use fetch with permission and keep its own settings, through the very commands an assistant calls over MCP.

⧉ 
<!-- index.html of a plugin -->
<button id="go">Round the selection</button>
<script>
  go.onclick = async () => {
    const nodes = await gigma.selection()
    await gigma.undoGroup(async () => {
      for (const n of nodes)
        await gigma.command('update_node', {
          id: n.id, cornerRadius: 16,
        })
    })
  }
</script>

Write it by hand or give the plugin docs to an AI along with your idea. Drop the .gplug file into Settings, Plugins, and it is ready to run from Ctrl+K.
